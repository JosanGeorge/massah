Arattai /storage Cross-Origin postMessage PoC (Finding F1)

Authorized internal security research only. This page demonstrates that any external origin can frame <target>/storage and drive the unauthenticated db-handler.js postMessage RPC to read/enumerate/write the victim's localStorage on the target origin, from an attacker page, using the victim's existing session cookies. Do not use outside an authorized test environment. See the companion report ../storage-bridge-cross-origin-report.md for full source evidence.
